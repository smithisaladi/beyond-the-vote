---
name: No product decisions without asking
description: Never make product/UX decisions autonomously — always ask the user first before changing behavior, adding fallbacks, or altering data display logic
type: feedback
---

Do not make product decisions without asking first.

**Why:** User wants control over product direction. I made a senator votes fallback to vote summaries and changed VotesTab to show extra states (result, null positions) without checking — this was unwanted.

**How to apply:** When a feature gap is found (e.g., missing data for senators), present the problem and options to the user instead of implementing a workaround. Only fix what was explicitly asked for. If the fix requires a judgment call about behavior/UX, ask.
